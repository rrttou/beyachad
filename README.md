# ביחד (Beyachad)

A React web app for school classes to foster social inclusion — "together, no one is alone."

## What it does

Students log in with a name and class code. The app then offers:

| Tab | Description |
|-----|-------------|
| **דיווח (Report)** | Send anonymous, named, or teacher-directed reports about social situations |
| **משימות (Tasks)** | Receive a random daily inclusion task (e.g. "invite someone to join the game") |
| **שגרירים (Ambassadors)** | View class ambassadors who connect students |

## Tech stack

- **React 18** + **Vite 5**
- **Firebase 12** — Anonymous Auth + Firestore

## Project structure

```
src/
  firebase.js          # Firebase init (Auth + Firestore), exports db, auth, loginAnon
  firebaseConfig.js    # Auto-generated by Firebase console — gitignored, not used in app
  App.jsx              # Root: handles auth state, persists user in localStorage
  main.jsx
  styles.css
  pages/
    Login.jsx          # Name + class-code form → Firebase anonymous auth
    Home.jsx           # Tab navigation after login
    Report.jsx         # Sends reports to Firestore /reports collection
    Tasks.jsx          # Random inclusion task display
    Ambassadors.jsx    # Class ambassadors placeholder
```

## Setup

1. Clone and install dependencies:
   ```bash
   npm install
   ```

2. Create `.env.local` in the project root with your Firebase project values:
   ```
   VITE_FIREBASE_API_KEY=...
   VITE_FIREBASE_AUTH_DOMAIN=...
   VITE_FIREBASE_PROJECT_ID=...
   VITE_FIREBASE_STORAGE_BUCKET=...
   VITE_FIREBASE_MESSAGING_SENDER_ID=...
   VITE_FIREBASE_APP_ID=...
   ```

3. In the [Firebase Console](https://console.firebase.google.com):
   - Enable **Anonymous Authentication** (Authentication → Sign-in providers)
   - Create a **Firestore Database** and add a `reports` collection

4. Start the dev server:
   ```bash
   npm run dev
   ```

## Firestore data model

### `/reports/{id}`

| Field | Type | Notes |
|-------|------|-------|
| `text` | string | Report content |
| `mode` | `"anon"` \| `"named"` \| `"teacher"` | Visibility mode |
| `classCode` | string | Class identifier |
| `uid` | string | Firebase anonymous UID |
| `senderName` | string | Populated only when `mode === "named"` |
| `time` | timestamp | `serverTimestamp()` |
